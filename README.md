# What Want — 把"读一遍"变成"做一遍"的自我认知平台

《如何找到想做的事》这本书的价值，在于带你完成「喜欢的事 × 擅长的事 × 重要的事 = 真正想做的事」这套自我梳理。但书只给问题、不给记录工具，跨步骤串联还得靠自己回忆。这个平台把全书做成可以一步步完成的工作流：书的正文在中间，左边是步骤导航，右边是每一步的提问与 AI 分析，你的答案会自动沉淀成一份跨章的个人档案。

这是一个**完全在你自己电脑上运行**的本地程序，数据不出本机。

---

## 怎么开始（三步）

**第一步：装好运行环境**
- 安装 Python（3.11 或更高版本，去 python.org 下载安装即可）。
- 把本项目从 GitHub 克隆到你的电脑。

**第二步：安装并启动**
打开命令行，进入项目里的 `platform/backend` 文件夹，依次执行下面四行：

```
python -m pip install -r requirements.txt
python seed_all_chapters.py
python scripts/seed_roles.py
python run.py
```

前三行是"装好依赖、准备好内置内容"，最后一行 `python run.py` 会启动程序。看到程序启动后，**打开浏览器访问 `http://localhost:8011/`** 就能使用了。

**第三步（可选）：补全书籍正文**
本项目已内置《如何找到想做的事》的**前 3 章 + 序言作为试用样本**，你可以直接打开体验"读正文 + AI 导师对话"。要解锁全部 8 章与书末题库，需要自己把剩余章节（第 4–8 章 + 问题清单）的正文放进 `chapter_md/` 文件夹（见下方说明）。

## 放入书籍正文（补齐剩余章节）

**放在哪里**
项目根目录已经有一个 `chapter_md/` 文件夹（里面内置了序 + 前 3 章的试用样本）。把剩下的章节文件按下面的规则补进这个文件夹即可，系统会自动识别并追加显示。

**怎么拆**
把整本书按下面 10 个部分切分，每部分一个 `.md` 文件。文件名**开头的几个字决定系统识别哪一章，必须照写**（横线后面的标题随便写，只用于显示）：

| 文件名开头（必写） | 对应内容 |
|---|---|
| `序-序言` | 书的序言 / 开篇 |
| `第1章-…` | 阻碍找到想做的事的 5 种误区 |
| `第2章-…` | 内外标准 |
| `第3章-…` | 自我认知法公式 |
| `第4章-…` | 重要的事（价值观） |
| `第5章-…` | 擅长的事 |
| `第6章-…` | 喜欢的事 |
| `第7章-…` | 真正想做的事 |
| `第8章-…` | 全书可视化流程图 |
| `问题清单` | 书末的价值观 / 才能 / 热情题库 |

**没放会怎样**
已内置的序 + 前 3 章可直接阅读与对话；未放入的第 4–8 章与问题清单也会显示在章节列表里（标题可见），但点开会提示你补正文。页面和练习流程照常能走，不会报错、不会崩。

## 关于 AI 导师（可选）

平台内置一位 AI 导师"刘老师"，会引用你前面写下的内容做苏格拉底式追问。要让他真正回答，需要一个 DeepSeek 的免费 API 密钥：
1. 去 DeepSeek 开放平台注册并创建密钥（以 `sk-` 开头）。
2. 在启动程序前，把环境变量 `DEEPSEEK_API_KEY` 设成你的密钥。

**没有密钥也能打开页面、走完所有练习流程**，只是点"对话 / 总结"时会提示缺少密钥。
