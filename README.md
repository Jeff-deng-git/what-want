# What Want — 交互式自我认知平台

把《如何找到想做的事》（八木仁平）从"读一遍"变成"做一遍"的本地 Web 平台。

书的价值在于完成「喜欢的事 × 擅长的事 × 重要的事 = 真正想做的事」这套自我认知流程，但书本身只给问题、不给记录工具，跨步骤引用还得靠人工回忆。这个平台把全书 8 章做成可逐步完成的工作流：章节正文在中间，左侧是步骤导航，右侧是每一步的提问与 AI 分析，答案沉淀成一份跨章档案。

---

## 它解决什么

- 书只提供问题，没有结构化的地方记录答案
- 通用笔记工具缺少角色化的 AI 分析能力（心理咨询师 / 职业规划师）
- 后续步骤需要引用前序步骤的答案，人工串联不可靠
- 已提炼并认同的关键词容易被新一轮 AI 提取覆盖掉

## 核心机制

**配置驱动的章节流程** —— 8 章各有独立的 JSON 配置，定义每一步的输入问题、AI 行为、输出结构与跨步引用关系；加章节或改流程不需要动代码。

**步骤级联与引用** —— 同章内后一步自动读取前一步的产出（如第四章：5 问 → 思维导图分组 → 可控性转化 → 优先级金字塔 → 工作目的）。

**跨章档案** —— 各章沉淀的关键结果写入统一的个人档案，供后续章节消费。第四章产出的价值观、排序与工作目的，会成为第七章组合、第八章实践的输入。

**常驻导师「刘老师」** —— 全书贯穿的苏格拉底式对话角色，能引用你在前面章节写下的内容做追问，不替你下结论。

**失效隔离** —— 回退修改已提交的步骤时，自动把下游步骤标记为过期并清空受影响的档案键，避免后续章节读到"新答案配旧结论"的脏数据。

**AI 不替用户定性** —— 所有 AI 产出都标为建议草稿，需用户确认提交后才生效；用户可编辑、锁定、重新生成，锁定项在重新生成时保留。

## 八章脉络

| 章 | 主题 | 作用 |
|---|---|---|
| 一 | 阻碍找到想做的事的 5 种误区 | 认知解构 |
| 二 | 内外标准 | 分辨哪些标准属于自己 |
| 三 | 自我认知法公式 | 建立「喜欢 × 擅长 × 重要」框架 |
| 四 | 重要的事（价值观） | 5 步级联，价值观源头 |
| 五 | 擅长的事 | 才能梳理 |
| 六 | 喜欢的事 | 热情梳理 |
| 七 | 真正想做的事 | 三者组合 |
| 八 | 全书可视化流程图 | 决策导航与复盘 |

## 技术栈

- **后端**：Python 3.11+ + FastAPI + SQLite（单用户本地部署，数据不出本机）
- **前端**：原生 HTML/CSS/JS 单页，无构建步骤
- **AI**：OpenAI 兼容接口，角色与提示词由配置定义
- **内容**：书籍正文由 PDF/EPUB 提取为 Markdown 与图片

## 快速开始

> **Python 版本**：需要 Python 3.11 或 3.12（推荐 3.11）；Python 3.13 也已验证可安装可运行。

```bash
cd platform/backend
python -m pip install -r requirements.txt

# 必需：8 章流程配置 → chapter_configs 表
python seed_all_chapters.py
# 必需：LLM 角色（导师「刘老师」/ 总结 / 心理咨询师 / 职业咨询师）→ llm_roles 表
#       chat 对话与 summary 总结功能依赖这些角色，不种会运行失败
python scripts/seed_roles.py
# 可选：题库（价值观/才能/热情 各 30 题）→ questions 表
#       需要自备书籍原文 chapter_md/问题清单.md；缺失时跳过即可（不影响其它功能）
python seed_questions.py

python run.py                   # 后端起在 :8011
```

然后打开 `platform/frontend/index.html`（或用任意静态服务器托管）。

**AI 能力需要自备密钥**（没有密钥时后端可启动、静态流程可走通，但 AI 分析会失败）：

```bash
export DEEPSEEK_API_KEY="sk-..."        # 或对应 provider 的 <PROVIDER>_API_KEY
# 也可以写入 platform/backend/data/secret.key（该文件不入库）
```

主要环境变量：`BACKEND_PORT`（默认 8011）、`WW_DB_PATH`（默认 `data/ww.db`）、`FRONTEND_ORIGIN`（默认 `http://localhost:3011`）。

> **前置条件（书籍原文需自备）**：以下功能依赖书籍正文，请自行将《如何找到想做的事》的 Markdown 提取结果放到项目根 `chapter_md/`：
> - ① 章节正文阅读（`chapter_md/` 下的章节 MD）；
> - ② 常驻导师「刘老师」对话（`/api/chapters/{id}/chat/send`）与章节总结（`/api/chapters/{id}/summary/regenerate`）会基于章节 MD 作答，缺书源时返回 404「No markdown source」；
> - ③ 第四章「100 例价值观清单」抽屉（读 `chapter_md/问题清单.md`，缺失时该抽屉为空，不会报错）。
>
> **其余流程与练习功能（章节步骤、跨章档案、失效隔离）由章节配置驱动，不依赖书籍原文。**

## 目录结构

```
What_Want/
├── llm_prompt_design/
│   └── config/          章节配置 JSON + 统一 Schema（chapters/ 是运行时权威契约）
└── platform/
    ├── backend/         FastAPI 服务（routers / runtime / services / tests）
    ├── frontend/        单页前端
    └── SPEC.md          架构规格
```

加章节或改流程不需要动代码：编辑 `config/chapters/` 下的 JSON，重新执行 `seed_all_chapters.py` 即可。字段契约以该目录下的配置为权威。
