## 1. 当前事实基线

### 1.1 权威交接文档已经确定的通用规则

以下内容不需要重新设计，除非设计侧明确提出变更并同步更新权威交接文档：

- `chapter_id` 使用 `ch01`–`ch08`。
- 运行时读取 `config/chapters/chapter_config_chNN.json`。
- `exercises[]` 中每个 exercise 对应一个前端 step 区块。
- 章节内级联使用 `exercises[].references`，从同章前序、已提交的 `step_runs.parsed_output` 读取；不能把章节内中间产物误当成 `learner_profiles`。
- 跨章节导师上下文使用 `learner_profiles` 和 `mentor_hooks.references`。
- `output_fields` 是落库字段契约；类型可以是 `text`、`editable_list`、`list`、`table`、`json` 等。
- 上游输出必须真正成为下游输入；缺失 producer 或字段时，应返回上下文错误或按设计明确降级，不能让流程表面成功但上下文为空。
- LLM 不能替用户作最终价值判断；`assist` 只能辅助归纳、纠偏、深化、找交集。
- LLM 输出需要能被稳定解析和渲染，不能只依赖自然语言或裸 JSON 的兜底显示。
