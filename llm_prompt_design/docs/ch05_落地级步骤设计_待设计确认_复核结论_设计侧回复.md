## §3. 100 例引用项时序 + canonical schema 统一 source（设计侧已修）

### 3.1 问题

**时序错误**：落地文档 §0/§step-2 line 61 注释写「step-1 的 `talents`（已含用户手动新增与 100 例引用项）」——但 100 例是在 step-2 抽屉点引用，时序上不可能已存在于 step-1 输出。

**canonical schema 表述省略 source**：交接 §7.5 ch05 表三行 + PRD §3.1.2 输出 schema 示例未统一写 `source?` 可选。

### 3.2 拍板（固定时序表述）

> 1. step-1 提交 → 产出 `step-1.talents`（仅 5 问答案衍生，**此时不含任何 100 例引用项**）；
> 2. step-2 进入 → 用户在「擅长的事 100 例清单」抽屉点「引用」 → 该项加入 `user_answers.reference_strengths`（**仍是用户输入态**，不在 `step-1.talents` 里）；
> 3. step-2 提交 → assembler 把 `step-1.talents` 与 `reference_strengths` 合并去重，喂给 LLM 首次运行 → 产出 canonical `talents`（含 `source:'100_examples'` 标记）；
> 4. 后续 step-2 重生成 → `preserve_output.talents` 锁定项原位置保留；非锁定项可重排/重生成。

**canonical schema 统一**：`{text, rating, locked, source?}`——四份权威文件表述对齐；`source` 仅 100 例引用项为 `'100_examples'`，5 问衍生为 `null`。
