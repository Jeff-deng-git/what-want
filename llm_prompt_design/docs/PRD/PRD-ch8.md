## 0. 关键发现：第八章是全书「决策导航页」，不是新的问答工作流

| 维度 | 第四章 | 第五章 | 第六章 | 第七章 | **第八章** |
|------|--------|--------|--------|--------|-----------|
| 核心任务 | 找到重要的事（价值观） | 找到擅长的事（才能） | 找到喜欢的事（热情） | 组合筛选出想做的事 | **全书可视化流程图（决策导航）** |
| 产出 | 工作目的/价值观 | 擅长清单 | 喜欢清单 | 真正想做的事 | **无 profile 产出（导航 + 备注）** |

**结论**：第八章采用 **「1 个独立流程图页」**（`page_type: "flowchart"`），不是练习/步骤流：

- 它是对整本书的**总结性决策导航**：按阶段展示决策点，用户对每个问题选「是/否/找到了/没找到」等分支，并可在每个决策点**写备注**（持久化、后续可查看）。
- 选「否/找不到」时**真实跳转**到对应章（ch04 价值观 / ch05 长处 / ch06 喜欢 / ch07 组合筛选）；选内部分支时在同一流程图内跳到下一决策点。
- **色彩浴、海胆、成功定义是书中的比喻与哲学阐述**，不是结构化练习步骤——作为阅读内容呈现，不强制、无 7 天表格、不落 profile。
- **无硬门禁**：进入不锁，仅软提示未完成的 ch04–ch07。

## 1. 第八章内容摘要（基于原书正文，作为「阅读层」而非「练习」）

### 1.1 色彩浴效应（图 8-1，P.200）
确定「想做的事」后，相关信息会自然映入眼帘。用户需竖起「天线」主动收集。**书里说的是"快则一周、慢则一个月找到实现手段"，并非"连续 7 天记录日志"**——故不做成结构化练习。

### 1.2 海胆比喻（图 8-2，P.204）
消极经历像海胆（黑壳带刺），剥开后是浓郁的海胆黄（经验）。自我认知就是打开海胆的技术。书里是作者 3 段亲身故事，**没有"用户写经历、LLM 转化"的练习结构**。

### 1.3 成功定义（P.206–208）
真正的成功不是金钱或名誉，而是"活出自我的当下"。

### 1.4 从寻找中"解脱"（P.209–211）
自我认知只是手段，目的是"热爱自己的生活"。

### 1.5 全书可视化流程图（P.212–213，决策导航核心）

> 以下为**修正后的**流程图（原 stale PRD 删去了「回答30问」兜底、且第 2 步误写为"工作目的 ch4"，实为"长处 ch5"；此处已按原书 md 末尾【全书可视化流程图文字说明】还原）。

```
开始：想做些事情，但不知道自己想做什么
  ↓
【阶段一·价值观】
dp-1 是否明确自己为何而活？
  是 / 找到了        → dp-2
  否                 → 前往《寻找自己的价值观！》(ch04)
  找不到             → 回答30问（ch04 value_questions）
  还是没找到         → 回答带⭐问题（=全部30问）→ 明确工作目的后 → dp-2
dp-2 是否明确工作目的？
  是                 → dp-3

【阶段二·长处】
dp-3 是否有能取得成果的长处？
  是 / 找到了        → dp-4
  否                 → 前往《寻找自己的长处吧！》(ch05)
  没找到             → 回答30问（ch05 talent_questions）

【阶段三·兴趣】
dp-4 有没有感兴趣或有热情的领域？
  否                 → 前往《寻找自己喜欢的领域吧！》(ch06)
  没找到             → 提示「喜欢的事终究只是实现工作目的的手段…」→ 回 dp-4
  是                 → 通过组合喜欢和擅长的事，假设想做的事（ch07）

【阶段四·提炼】
dp-refine 通过工作目的提炼出想做的事？
  去提炼             → ch07 筛选定稿
  提炼成功           → dp-5
dp-5 是否找到实现真正想做的事的手段？
  找到了             → 终点
  没找到             → 通过书/网络/研讨会等收集信息 → 终点

【终点】
辛苦了！全身心投入到实现真正想做的事情中去吧！
```

图中「回答30问 / 带⭐问题」即跳转对应章的 30 问（`value_questions`/`talent_questions`/`passion_questions`）；「带⭐」按用户定义 = 该章全部 30 问（系统当前无 starred 子集）。

## 2. 可交互元素

### 2.1 流程图决策导航（核心）
- 按 `config.chapter_config_ch08.json` 的 `flowchart.stages[].decision_points[]` 渲染。
- 每个决策点 = 一张「问题卡」：问题文案 + N 个分支按钮（label）+ 可选备注框。
- 选内部分支 → 跳到 `next` 决策点；选 `jump` 分支 → **真实跳转到对应章**（离开 ch08，返回时恢复到离开前决策点）。

### 2.2 每决策点备注
- `comment_enabled: true`：每个问题卡下方有备注输入框，写入 `flowchart_state.comment_text`，后续可查看/编辑。

### 2.3 真实跳转
- `jump.chapter` = 目标章（ch04/ch05/ch06/ch07）；`jump.question_key` 可选（指向该章 30 问）；`jump.hint` 为 UI 跳转说明文案。

### 2.4 软提示门禁（无硬锁）
- 进入 ch08 时后端读 ch04–ch07 的 profile 完成态（含 `stale=0` 校验），顶部显示引导：「建议先完成：ch04 价值观 / ch05 长处 / ch06 喜欢 / ch07 想做的事」，每项带「前往」按钮。
- 不阻断访问；上游 stale 时标注「数据可能已过期，建议重跑」。

### 2.5 阅读层（色彩浴 / 海胆 / 成功定义）
- 作为章节阅读内容呈现（原书 P.199–211），不强制任何练习、不落 profile、无 7 天表格。
- 可附「灵感便签 / 我的海胆（可选反思）/ 我的成功宣言（一句话）」等轻量、非强制的本地记录入口，定位为阅读延展，不进入核心流程图。

## 5. 数据模型

### 5.1 `flowchart_state` 表（新增，与 profile 解耦）

```sql
CREATE TABLE flowchart_state (
  id                INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id           TEXT NOT NULL DEFAULT 'local',
  chapter_id        TEXT NOT NULL DEFAULT 'ch08',
  decision_point_id TEXT NOT NULL,
  selected_branch   TEXT,
  comment_text      TEXT,
  updated_at        TEXT DEFAULT (datetime('now')),
  UNIQUE(user_id, chapter_id, decision_point_id)
);
```

- 每个决策点一行；重访按 `(user_id, decision_point_id)` 恢复备注与上次选择。
- **零 profile 写入**：不写 `learner_profile`、不进 `compaction.py` 白名单，无 DRIFT 风险。
