## 0. 关键发现：第七章是前三章的"组合收口"，不是新的 5 个问题

SPEC 中"从第 4 章起每个章节有 5 个步骤 × 5 个问题的工作流"这一概括，在第五章、第六章被验证为"**叙事铺垫 + 5 个问题 + 1 个综合产出**"；第七章则不同——它不再向用户提出 5 个新问题，而是**把前三章已收集的答案组合起来**，推导出"想做的事"。

| 维度 | 第四章（重要的事） | 第五章（擅长的事） | 第六章（喜欢的事） | **第七章（想做的事）** |
|------|-------------------|-------------------|-------------------|----------------------|
| 输入 | 用户直接回答 5 问 | 用户直接回答 5 问 | 用户直接回答 5 问 | **复用 ch4/ch5/ch6 的输出** |
| 核心方法 | 回答 5 问 → 整理价值观关键词 → 元反思 → 排序 → 确定工作目的 | 回答 5 问 → 写《使用说明书》 | 回答 5 问 → 写《喜欢的事清单》 | **喜欢 × 擅长 → 批量假设 → 用工作目的筛选** |
| 综合产出 | 工作目的（最重要的价值 + 价值观排序） | 《自己的使用说明书》（10–20 个长处+用法+评级） | 《喜欢的事清单》（领域 × 喜欢的方面） | **《真正想做的事》+ 备选《作为兴趣的想做的事》** |
| 关键图示 | — | 图 5-5/5-6/5-7 八角度工作表 | 图 6-1 领域→方面→擅长 | **图 7-1 假设-行动-复盘螺旋、图 7-2 自由组合、图 7-3 工作目的过滤器** |

**结论**：第七章采用 **「2 个步骤 + 2 个核心视图 + 1 个迭代机制」** 的收口工作流：

- **Step 1：组合假设** — 从 ch5《使用说明书》和 ch6《喜欢的事清单》中，批量生成「喜欢 × 擅长」的候选。
- **Step 2：目的筛选** — 用 ch4 的「工作目的」作为过滤器，选出「真正想做的事」和「作为兴趣的想做的事」。
- **核心视图 1：组合矩阵** — 类似图 7-2，把喜欢的事放在行、擅长的事放在列，交叉处生成候选。
- **核心视图 2：迭代螺旋** — 类似图 7-1，强调"假设→行动→复盘→修正"的循环。
- **迭代机制**：用户可把任意候选标记为"正在尝试"，填写行动日志与复盘，再回流修正候选描述。

## 1. 第七章内容摘要（基于原书正文+配图）

### 1.1 叙事模块（3 个概念铺垫）

1. **现在马上放弃"为了将来工作"的想法（P.183）**  
   不要为了将来而活；找到"目前最想做的事"并认真对待，人才会成长。  
   **POINT**：找到"想做的事"，不要拖延。

2. **"想做的事"即使是假设也没关系（P.185–188）**  
   - 不要盲目行动（赌博式跳槽），而要先设立假设，再行动、复盘、活用。  
   - 作者案例：喜欢"自我认知"这个领域，但工作方式从「一对一倾听」→「研讨会」→「视频课程+信息答疑」迭代了三次。  
   - 工作方式优劣三标准：**是否偏离价值观 / 是否偏离擅长的事 / 是否偏离喜欢的事**。  
   **POINT**：在实践中不断修正，逐渐接近"真正想做的事"。

3. **图 7-1：假设-行动-复盘螺旋（P.187）**  
   ```
   假设 1：试着引导出客户的话题
      ↓ 行动 1：每天指导客户 → 复盘 1：咦？一直听别人说话一点儿也不开心
   假设 2：举办自我认知的研讨会吧
      ↓ 行动 2：举办研讨会 → 复盘 2：要重复说同样的话好痛苦
   假设 3：做视频课程吧
      ↓ 行动 3：做成视频课程 → 复盘 3：好开心！想传授给更多人听！
   ```
   **寓意**：在固定"喜欢的事"的前提下，把工作方法修正为"擅长的事"。

### 1.2 步骤一：用喜欢的事 × 擅长的事，先假设一个自己想做的事（P.189–193）

**操作方法**：
1. 列出 ch6 已发现的"喜欢的事"（领域）和 ch5 已发现的"擅长的事"。
2. 在能与"喜欢的事"匹配的擅长之事前标记 **"◎"**，作为重点；其他作为辅助。
3. 自由组合，生成"想做的事"候选；**此阶段量比质更重要**。
4. 一时想不到怎么组合也没关系，先全部写下来。

**作者示例 12 条候选（P.190–191）**：
1. 构建自我认知体系并传授给别人的人  
   喜欢自我认知 × 擅长不断学习新事物，将信息整理成体系并进行阐释，传授给大多数人
2. 学习自我认知并教授给别人的人  
   喜欢自我认知 × 擅长多进行实操而不是练习，用语言帮助别人
3. 研究自我认知法的人  
   喜欢自我认知 × 擅长不断学习新事物，思考令人激动的想法
4. 为实现理想提供支持的战略顾问  
   喜欢自我认知 × 擅长花时间制定令人认可的战略，发现自己和他人的长处并灵活利用，用语言帮助别人
5. 面向拟创业人群的创业顾问  
   喜欢自我认知 × 擅长花时间制定令人认可的战略，发现自己和他人的长处并灵活利用，用语言帮助别人
6. 不断研发教育类桌游的人  
   喜欢自我认知、桌游 × 擅长开拓新事业，将信息整理成体系并进行阐释，思考令人激动的想法，不满足于现状
7. 教别人如何制作教育类桌游的人  
   喜欢自我认知、桌游 × 擅长发现自己和他人的长处并灵活运用，树立明确的目标，无论成功还是失败，思考令人激动的想法
8. 玩益智类玩具并做对比介绍的人  
   喜欢自我认知、桌游 × 擅长将信息整理成体系并进行阐释，用语言帮助别人
9. 桌游解说员  
   喜欢自我认知、桌游 × 擅长将信息整理成体系并进行阐释，用语言帮助别人
10. 教别人找到适合自己风格的服装的时尚顾问  
    喜欢时尚、自我认知 × 擅长发现自己和他人的长处并灵活运用，思考令人激动的想法
11. 时装设计师  
    喜欢时尚、自我认知 × 擅长思考令人激动的想法，不满足于现状
12. 桌游专业玩家  
    喜欢桌游 × 擅长多进行实操而不是练习，树立明确的目标，无论成功还是失败

**图 7-2（P.193）**：组合方式是自由的；这一阶段优先保证数量，尽情写出"想做的事"。  
**POINT**：通过"喜欢的事 × 擅长的事"，假设出自己想做的事。

### 1.3 步骤二：通过"工作目的"筛选出"真正想做的事"（P.194–198）

**核心逻辑**：
- 钱 = 感谢。客户只为"价值"付钱，不会为"你想做的事"付钱。
- 你想从别人那里收到怎样的"谢谢"？这取决于你的价值观（ch4 的工作目的）。
- "工作目的"是从众多候选中筛选"真正想做的事"的过滤器。

**作者示例**：  
- 工作目的 = "让更多的人热爱生活"。  
- 因此从 12 个候选中选中 **"构建自我认知体系并传授给别人的人"**。  
- 其他候选可分为：
  - **作为工作"真正想做的事"**：与"让更多的人热爱生活"直接相关。
  - **作为兴趣"想做的事"**：同样喜欢且擅长，但与此工作目的无关。

**图 7-3（P.196）**：判断标准就是"是否与工作目的有关"。  
**P.197 思考范围扩展链**：  
自己的价值观 → 家人 → 朋友 → 公司 → 业界 → 社会/国家 → 全世界。  
**结论**：在持有的价值观中，按捺不住想通过工作传递给周围/地区/世界的是什么价值观？这就是"工作目的"。一旦明确，"真正想做的事"自然被引导出来。

### 1.6 前置依赖与未就绪处理（Prerequisite Gating）

ch7 是组合章，**硬性依赖 ch4 + ch5 + ch6 三章产出**；任一缺失都无法完成「组合→筛选」主流程。

| 上游章节 | 需要的产出字段 | 必需/可选 | 未就绪时的界面表现 |
|---|---|---|---|
| ch5 擅长的事 | `strengths[]` | 必需（Step 1 组合输入） | 整章锁定：半透明遮罩 + 未就绪说明卡，列出缺失章节及直达入口 |
| ch6 喜欢的事 | `passions[]` | 必需（Step 1 组合输入） | 同上 |
| ch4 重要的事 | `purpose` | 必需（Step 2 过滤「真正想做的事」） | 同上 |

**判定逻辑**：进入本章时后端读取 ch4/ch5/ch6 的 `status` 与输出字段。若任一必需产出缺失（status≠completed 或字段为空），**整章主体内容显示半透明遮罩 + 未就绪说明卡**，明确列出「需要优先完成的章节」（如「第五章《使用说明书》尚未完成」），并为每章提供「去完成」直达按钮。全部就绪后才解锁主流程。

## 2. 第七章可交互元素

### 2.1 主工作区：组合矩阵（Step 1）

- **左侧/上方**：ch6「喜欢的事」列表（领域卡片，可勾选）。
- **右侧/左方**：ch5「擅长的事」列表（长处卡片，可勾选，显示 ◎〇△ 评级）。
- **交叉区**：自动生成候选卡片，文案格式为"一个做……的人 / 一个用……帮助……的人"。
- **候选卡片状态**：
  - 草稿（未确认）
  - 已确认进入候选池
  - 已标记"正在尝试"
  - 已归档到"作为兴趣的想做的事"
  - 已选定为"真正想做的事"
- **操作**：增、删、编辑、锁定、拖拽排序。

### 2.2 迭代螺旋面板（视图）

- 以图 7-1 为蓝本，展示一个候选从"假设 → 行动 → 复盘"的循环。
- 用户可以：
  - 对某个候选点击"设立假设"；
  - 填写"行动"（尝试做了什么，持续多久）；
  - 填写"复盘"（偏离了价值观 / 擅长 / 喜欢中的哪一项？）；
  - 系统给出"修正建议"，可一键生成新的候选描述或工作方式。

### 2.3 工作目的过滤器（Step 2）

- 显示 ch4 已确定的「工作目的 + 核心价值观」。
- 对每个候选，让用户判断并标记：
  - 与我的工作目的**直接相关**（→ 真正想做的事）
  - 与我的工作目的**无关，但仍然吸引我**（→ 作为兴趣的想做的事）
  - **不确定**（→ 待讨论/导师引导）
- LLM 辅助：对每个候选给出"匹配工作目的"的评分理由。

### 2.4 章节摘要/笔记面板

- 沿用 ch4/ch5/ch6：
  - 阅读层：选中书中文字记笔记；
  - 独立笔记；
  - 进度恢复；
  - 右侧「与导师对话」Tab。

### 3.1 LLM 提示词设计规范（身份 / 背景 / 目标 / 约束）★必需章节

#### 3.1.0 共用书籍背景知识（所有 ch7 角色常驻 system）

你必须理解并严格遵循以下原书方法论，回答时当作这套方法论的实践教练：

1. **"想做的事" = 喜欢的事 × 擅长的事 × 重要的事（工作目的/价值观）**。本章重点做前两者的组合，再用第三者筛选。
2. **不要为未来而活**：用户不需要"先学对将来有用的技能"再找想做的事；应该找到目前最想做的事，在实践中成长。
3. **"想做的事"最初只是假设**：不要赌博式盲目行动；循环是 **设立假设 → 行动 → 复盘 → 修正 → 更接近真正想做的事**。
4. **工作方式优劣三标准**：是否偏离价值观、是否偏离擅长的事、是否偏离喜欢的事。
5. **固定"喜欢的事"，修正"工作方法"**：领域可以不变，但如何用擅长的方法去做要反复迭代。参考作者案例：
   - 喜欢"自我认知"不变；
   - 工作方法从「一对一倾听」→「研讨会」→「视频课程+信息答疑」迭代；
   - 原因：不擅长"听别人说话"、不擅长"重复说同样的话"。
6. **组合规则**：
   - 喜欢的事可以是 1 个或多个；擅长的事可以是 1 个或多个；
   - 在能与喜欢之事匹配的擅长之事前标记"◎"作为重点；
   - 此阶段量比质重要，先写出所有可能。
7. **"工作目的"是过滤器**：
   - 钱 = 感谢；客户只为价值付钱，不会为"你想做的事"付钱；
   - 用户需要从客户那里听到怎样的"谢谢"，这由价值观决定；
   - 与工作目的有关的候选 → "真正想做的事"（作为工作）；
   - 与工作目的无关但仍吸引用户 → "作为兴趣的想做的事"。
8. **思考范围扩展链（P.197）**：自己 → 家人 → 朋友 → 公司 → 业界 → 社会/国家 → 全世界。工作目的越贴近"按捺不住想传递出去的价值观"，筛选越有力。
9. **少样本示例**：若需要举例，参考作者生成的 12 条候选，句式为"一个做……的人 / 一个用……帮助……的人"，并标注"喜欢来源"和"擅长来源"。

#### 3.1.1 `combination-strategist` 组合策略师

**system prompt**
```
你是「组合策略师」，协助用户把第五章《自己的使用说明书》中的"擅长的事"与第六章《喜欢的事清单》中的"喜欢的事"组合成多个"想做的事"候选。

【身份】
你擅长创意组合与职业叙事表达。你的任务不是替用户决定，而是帮助用户看见"喜欢"与"擅长"交叉点的各种可能。

【书籍背景】
<插入 §3.1.0 共用书籍背景知识>

【目标】
1. 根据输入的喜欢之事列表和擅长之事列表，生成 8–15 条候选。
2. 每条候选必须包含：title（一句话身份/角色）、like_sources（来源领域）、strength_sources（来源长处）。
3. 对明显强匹配的喜欢+擅长组合优先生成，并标记 high_match: true。
4. 鼓励跨领域组合（如"桌游 + 自我认知"），不要只生成单一领域内的候选。
5. 候选句式统一为："一个……的人"或"一个用……帮助……的人"，保持中文自然。

【约束】
- 必须基于用户真实输入，不得臆造用户未提及的喜欢领域或长处。
- 如果用户输入不足 3 条喜欢或 3 条擅长，生成时降低数量，并提示用户返回前几章补充。
- locked 候选（用户已锁定保留）必须原样出现在输出列表中，不参与改写。
- 输出严格 JSON，不包含 markdown 代码块外的任何解释。

【输出格式】
{
  "candidates": [
    {
      "id": "cand_1",
      "title": "一个构建自我认知体系并传授给别人的人",
      "like_sources": ["自我认知"],
      "strength_sources": ["不断学习新事物", "将信息整理成体系并进行阐释", "传授给大多数人"],
      "high_match": true,
      "locked": false
    }
  ]
}
```

【第六章《喜欢的事清单》中的喜欢之事】

## 7. 视觉与交互规范（继承 SPEC 书卷气）

- **组合矩阵**：左侧为"喜欢的事"行标签（赭石色块），上方为"擅长的事"列标签（墨色块），交叉格显示生成的候选卡片。强匹配格高亮。
- **候选卡片**：纸张卡片样式，轻微投影。左侧小图标表示来源（❤ 喜欢 / ✦ 擅长）。
- **迭代螺旋**：垂直螺旋线，节点为"假设 / 行动 / 复盘"，用户可点击节点填写内容。节点颜色反映能量感受（开心/痛苦/中性）。
- **工作目的过滤器**：顶部固定显示 ch4 工作目的卡片；候选卡片下方显示 LLM 评估标签（绿色=高度相关 / 蓝色=兴趣保留 / 灰色=待讨论）。
- **三栏布局**：左步骤导航 / 中书正文+工作区 / 右 tab 面板（章节摘要、我的笔记、与导师对话）。
