## 1. 第八章内容摘要（基于原书正文+配图）

### 1.1 叙事模块 1：如何找到实现"想做的事"的手段（P.199–202）

- **核心观点**：不必提前考虑实现手段；一旦确定"想做的事"，手段会自然浮现。
- **色彩浴效应**（图 8-1，P.200）：  
  确定想做的事后，相关信息会源源不断映入眼帘。用户需要竖起"天线"，主动收集对自己有用的信息。
- **学习对象**：实现方法可以从"已经做到这件事的人"那里学到（研讨会、书籍、网络、他人经验等）。
- **时间预期**：快则一周，慢则一个月就能找到实现手段。
- **作者案例**：决定"构建自我认知体系并传授给别人"后，偶然看到"教你如何扩大讲座型项目"的文章，参加研讨会，不到一年做出 200 人项目。
- **客户案例（H 先生）**："想做的事"是"让更多人在森林中直面自己，控制身心"，通过调查找到"森林浴项目培训讲座"，产生"命运的邂逅"。
- **POINT**：如果决定了"想做的事"，自然就可以找到实现手段。

### 1.2 叙事模块 2：掌握自我认知法，今后再也不会失败（P.203–205）

- **核心观点**：自我认知能把所有人生经历（包括失败和后悔）变成"经验"。
- **海胆比喻**（图 8-2，P.204）：  
  消极经历像海胆——又黑又有刺，让人害怕；但剥开壳后，里面是浓郁的海胆黄（经验）。自我认知就是打开海胆的技术。
- **作者案例**：
  - 便利店打工被解雇 → 意识到不擅长按别人指示做既定工作 → 后来开公司、只做喜欢的事。
  - 100 次搭便车旅行仍怕生 → 发掘"一个人能埋头做事"的长处 → 支撑写博客、出书。
  - 为钱写不感兴趣的文章导致抑郁 → 确信"必须把喜欢的事作为工作"。
- **POINT**：失败和后悔都会通过自我认知变成经验。

### 1.3 叙事模块 3：所谓成功并不是"达成目标"，而是"活出自我的这个瞬间"（P.206–208）

- **核心观点**：真正的成功不是金钱或名誉，而是"活出自我的当下"。
- 金钱和名誉只是附加产物；如果对现在做的事感到充实，那才是成功。
- 作者曾为了"月入 100 万日元"接不认同的广告，心里有个疙瘩；后来放弃这种"博主"模式，自己制作并销售真正想推荐的商品。
- **POINT**：活出自我就是成功；在此基础上还能做出成果就是大成功。

### 1.4 叙事模块 4：尽快从寻找想做的事中"解脱"出来，成为"忘我的自己"（P.209–211）

- **核心观点**：自我认知只是手段，目的是"热爱自己的生活"。
- 不知道"真正想做什么"就像在跑没有终点的马拉松；明确后，人生就像游戏一样沉浸。
- 最终目标：通过自我认知实现忘我生活方式，并把这种方式传授给周围的人。
- **POINT**：找到"想做的事"之后，开启最棒的人生。

### 1.5 全书可视化流程图（P.212–213）

作为本书"结束语"，以流程图形式总结找到"真正想做的事"的完整路径：

```
开始：想做些事情，但不知道自己想做什么
  ↓
是否明确自己为什么而活？
  否 → 寻找自己的价值观吧！（ch4）
  是 → 是否明确工作目的？
         否 → 寻找/明确工作目的（ch4）
         是 → 是否有能取得成果的长处？
                否 → 寻找自己的长处吧！（ch5）
                是 → 有没有感兴趣或有热情的领域？
                       否 → 寻找自己喜欢的领域吧！（ch6）
                       是 → 通过组合喜欢和擅长的事，假设一个想做的事（ch7）
                              ↓
                       通过"工作目的"提炼出"想做的事"（ch7）
                              ↓
                       是否找到实现真正想做的事的手段？（ch8）
                              否 → 通过书、网络、研讨会等收集信息（ch8 Step 1）
                              是 → 结果：全身心投入到实现真正想做的事情中去吧！
```

## 2. 第八章可交互元素

### 2.1 Step 1：竖起天线——实现手段清单

- **输入**：自动带入 ch7 选定的「真正想做的事」标题与描述。
- **用户操作**：
  - 写下目前已知的实现手段（书/课程/研讨会/人/社群/工具等）；
  - 从书中提到的类型中选择：书、网络、研讨会、已经做到的人、讲座、社群；
  - 给每个手段标注状态：已了解 / 已报名 / 已实践 / 已放弃。
- **LLM 辅助**：根据「真正想做的事」自动生成 5–10 条可能的实现手段建议。
- **视觉**：像"天线"一样竖起的清单；每条手段是一个小卡片，带类型图标。

### 2.2 Step 2：剥海胆——消极经历转化日记

- **输入**：用户自由书写一段失败、后悔或痛苦的经历。
- **LLM 辅助（海胆转化器）**：帮助用户从经历中提炼：
  - 这段经历让我意识到自己不擅长什么；
  - 这段经历让我发现了什么长处/价值观；
  - 这段经历如何支持了现在的"想做的事"。
- **输出**：一条"海胆转化记录"，结构为：
  - 原始经历（黑刺外壳）
  - 当时的痛苦/情绪
  - 提炼出的经验/长处/价值观（海胆黄）
  - 与当前"想做的事"的关联
- **视觉**：左侧是带刺的海胆图标，右侧是金黄色的经验卡片；转化成功后海胆图标变成打开状态。

### 2.3 Step 3：成功宣言

- **输入**：ch7 的"真正想做的事" + ch4 的价值观。
- **用户操作**：
  - 选择/填写自己的成功定义（默认从书中提取："活出自我的当下"）；
  - 写下"我不会为了金钱/名誉对自己说谎"的具体承诺；
  - 写下"如果只能对客户/世界说一句话，我想说什么"。
- **输出**：一张可导出/分享的「成功宣言」卡片，带用户姓名和日期。

### 2.4 全书总览视图：可视化流程图

- 以 P.213 流程图为蓝本，做成可交互的全书地图。

- 支线提示：若某章产出不足，显示"去回答 30 问"的快捷入口。

### 3.1 LLM 提示词设计规范（身份 / 背景 / 目标 / 约束）★必需章节

#### 3.1.0 共用书籍背景知识（所有 ch8 角色常驻 system）

你必须理解并严格遵循以下原书方法论，回答时当作这套方法论的实践教练：

1. **第八章是全书收尾章**：不再回答新问题，而是帮助用户把第七章找到的"真正想做的事"落地，并把过去的消极经历转化为经验。
2. **色彩浴效应**：一旦确定"想做的事"，实现手段所需的信息会自然映入眼帘。用户需要竖起天线、主动收集；实现手段在社会上比比皆是，不必提前知道所有答案。
3. **时间预期**：快则一周，慢则一个月就能找到实现手段。
4. **学习对象**：实现方法可以从"已经做到这件事的人"那里学到——书、网络、研讨会、讲座、社群、导师等。
5. **海胆比喻**：
   - 消极经历（失败、后悔、痛苦）像海胆——外表又黑又有刺，让人害怕；
   - 但剥开壳后，里面是浓郁的海胆黄（经验）；
   - 自我认知就是打开海胆壳、取出海胆黄的技术；
   - 不要对正在痛苦的人说"向前看"，但要等平静后帮助他们从经历中学习。
6. **成功定义**：
   - 真正的成功不是金钱或名誉，而是"活出自我的这个瞬间"；
   - 金钱和名誉只是附加产物，是"将自己提供给社会的价值"的数据化；
   - 只要不对自己说谎、诚实地生活，就是成功；在此基础上做出成果，就是大成功。
7. **自我认知只是手段**：目的是"热爱自己的生活"，最终成为"忘我的自己"。
8. **全书流程**：找到重要的事（价值观）→ 找到擅长的事（才能）→ 找到喜欢的事（热情）→ 组合并筛选 → 找到实现手段 → 全身心投入。
9. **语气**：温和、鼓励、不急躁、不替用户下结论。

【身份】
你温和、有耐心，不否定用户的痛苦，也不强行鸡汤。你的工作是陪伴用户从经历中看见自己的长处、价值观和未来方向。

【书籍背景】
<插入 §3.1.0 共用书籍背景知识>

- 海胆比喻：消极经历是带刺的黑外壳，里面是经验；

- 不能轻视用户的痛苦（避免"这没什么大不了"）。
- 不能编造用户没有提到过的长处或价值观。
- 输出严格 JSON。

【输出格式】
{
  "original_experience": "在便利店打工被解雇",
  "emotion": "沮丧、羞耻",
  "lessons": [

## 5. LLM 介入点（与 §3.1 对应）

**提示词去哪看**：上表只说明「哪个场景由哪个角色负责做什么」。每个角色的具体提示词——身份设定、需要内化的书籍背景、目标、约束，以及可调用的 `user` 模板——统一在 **§3.1 LLM 提示词设计规范** 中给出。后端调用时按该节把书籍背景作为 `system` 常驻注入、把用户答案作为 `user` 传入。

| 触发时机 | 角色 | 输出 |
|----------|------|------|
| 用户进入 Step 1 | `means-finder` | JSON 实现手段建议 |
| 用户在 Step 2 提交消极经历 | `experience-reframer` | JSON 转化经验 |
| 用户在 Step 3 提交成功想法 | `success-clarifier` | JSON 成功宣言 |
| 用户打开全书总览视图 | `journey-summarizer` | JSON 各节点摘要 |
| 右侧导师对话任意时机 | `mentor` | 自然语言引导 |

## 7. 视觉与交互规范（继承 SPEC 书卷气）

- **Step 1 实现手段清单**：竖形"天线"视觉隐喻，手段卡片像信号一样排列在右侧；类型用图标区分（📚书 / 🌐网络 / 🎤研讨会 / 👤人 / 👥社群）。
- **Step 2 海胆日记**：左侧闭合的海胆图标（黑色带刺），转化成功后动画打开，露出右侧金黄色的经验卡片。情绪标签用低饱和色，经验标签用暖金色。
- **Step 3 成功宣言**：纸张卷轴/证书样式，可导出为图片。关键句加粗，底部签名栏。
- **全书总览视图**：水平/垂直流程图，节点用圆角矩形；已完成节点为赭石色，当前节点高亮脉冲，未解锁节点为浅灰。节点之间用虚线箭头连接。
- **前置锁定**：若 ch7 未完成，中央显示半透明遮罩 + "请先完成第七章"按钮。
